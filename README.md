# E+++ Solutions

Government-recognized computer training institute website (Kozhikode / Palayam).

## Live site

https://eplusplus-solutions.vercel.app

## Local run

Open `index.html` in a browser, or:

```bash
npx serve .
```

## Structure

- `index.html` — layout (header, footer, WhatsApp float)
- `assets/js/app.js` — SPA pages & content
- `assets/css/style.css` — styles
- `assets/images/` — logos and icons
